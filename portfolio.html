🚀 Quick Start

  1. Copy all system files to ServerScriptService/Systems/
  2. Copy utility files to ServerScriptService/Modules/
  3. Place GameLoader.lua in ServerScriptService/
  4. Copy UI scripts to StarterPlayer/StarterPlayerScripts/
  5. Run the game - all systems auto-initialize
